# 1.0.49

Windows 控制 Windows 时，开启“原生补清”可以在停下操作后补回鼠标附近的小字。本次对照中，同样的 40 个文字图块从 110,909 字节降到 77,485 字节，接收后的像素与原图一致。窗口太小时暂停补传，放大后自动恢复。

Windows 查看端的“新版放大”右键菜单新增“文字笔画”。从 1.75 倍起增强已有笔画，轻度放大使用双三次。压缩过的深色终端在本轮样本中用 NIS 更清楚，NIS 仍是初始选项。

修复 Windows 远控画面在桌面长时间静止后可能停在旧帧的问题。重新操作后，Windows 查看端会按需请求关键帧。Windows 和 Android 也调整了空闲后对延迟到达的视频分片的处理。
