# 1.0.20

修复 Windows 锁屏时连接后立即断开的问题。

- 不再提供“仅 H.264、不可用即断开”选项，历史设置自动迁移。正常桌面仍优先 H.264；锁屏或编码不可用时可回退 JPEG。
- 被控端兼容旧 Windows 客户端的“仅 H.264”设置：对方支持 JPEG 时，锁屏画面也能正常显示。
- 公网 TCP 传输不再反复发送完全相同的锁屏画面，减少带宽占用和排队。画面变化立即发送，静止时定期刷新；不会因此降低画质或误降分辨率。

Linux、Android 随版重新打包，本次没有新增功能。Windows 锁屏控制仍需辅助服务，不绕过系统登录验证。Android 录屏授权和 Linux Wayland 限制不变。

沿用预发布标记及 Android 原签名；Windows EXE 未做 Authenticode 签名。
