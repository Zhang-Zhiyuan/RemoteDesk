# RemoteDesk 1.0.37

- Windows 远控窗口独立显示，主窗口最小化或隐藏到托盘时不再跟着消失。
- Windows 控制 Windows 时，可用“多屏分窗”把两块远端屏幕分别打开，最多支持 4 块。两端都需更新，Linux、Android 暂时仍使用屏幕切换。
- 关闭其中一个窗口不影响另一个，隐藏屏幕暂停采集；剩余窗口可以重新打开它。新控制端接管时，旧控制端的全部屏幕一起断开。
- Windows 被控端的每块屏幕各显示一条被控提示，不抢输入焦点。任意一条上的“断开”都会结束这台电脑的全部远控连接。提示不覆盖系统锁屏或登录界面。
- 修复屏幕窗口重复打开、旧连接清理干扰新连接等边界情况；副屏掉线时保留屏幕身份，不悄悄切到主屏。

未降低码率、分辨率或画质。三端安装包统一为 1.0.37，Android 沿用原签名，继续按预发布提供。Ubuntu 22.04 请用 system-python 便携包；amd64 deb 要求 glibc 2.38。
