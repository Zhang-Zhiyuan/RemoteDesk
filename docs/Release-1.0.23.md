# 1.0.23

- Windows 控制 Windows 时新增“原生补清”开关，与原来的放大增强并列，默认关闭。
- H.264 保持动态画面，停止操作后逐步补充鼠标附近的原始像素，改善低分辨率传输后的文字清晰度。
- 输入、拥塞、显示积压时暂停补清；开启时沿用当前传输尺寸，关闭可恢复 UDP 视频，不用重连。
- 修复静态画面补清停滞、快速开关状态错乱，以及硬件暂不可用时关闭请求未发出的问题。

目前补清仅限兼容 GPU 的 Windows 单屏会话，区域最多 1024×1024。Linux / Android 保留原有
硬解、放大和连接方式；不需要重新配置中继、设备密钥或权限。

这是可选实验功能，不保证所有设备零额外开销。已有本地和真实公网的原始像素、中文输入、
反复切换实测；手机本轮未连接，未把跨语言协议测试当成手机真机验证。
详细结果见[实测记录](NativeDetailHost-20260914.md)。
