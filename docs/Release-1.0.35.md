# RemoteDesk 1.0.35

- Windows、Linux、Android 支持 IPv4 / IPv6 直连和设备发现，中继可记录两类地址。长地址显示时区分 IP 与端口。
- 直连尝试交替使用 IPv4、IPv6 地址，不再让一个不可达地址阻塞其他地址；只在连接成功的线路上认证，不增加视频缓冲。
- Windows 在后台、最小化或远控期间停止自动扫描附近设备。Linux 减少空闲轮询，列表只更新变化的行，保留选择和滚动位置。
- 修复 Windows 小窗口、大字体下标签、按钮、复选框文字遮挡，以及操作区换行后高度不正确的问题。

本轮没有降低码率、分辨率或画质参数。已在 Windows 隔离桌面、WSL/X11 和 Android 模拟器检查网络与界面；模拟器不代表手机真机兼容认证。

IPv6 直连需要可达地址和相应防火墙规则；服务端也需更新，才能保存和转发 IPv6 地址信息。当前测试用公网中继没有分配公网 IPv6，不能据此宣称已完成公网 IPv6 跨设备验证。

三端安装包统一为 1.0.35，沿用 Android 签名及预发布标记。Ubuntu 22.04 请用 system-python 便携包；amd64 deb 要求 glibc 2.38。
