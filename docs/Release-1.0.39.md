# RemoteDesk 1.0.39

- Windows / Linux 新增传输任务面板，可查看进度、保存回执和取消任务；Android 支持一次选择最多 32 个文件。
- 三端新增“仅观看”开关。暂停键鼠和剪贴板写入时，画面和已确认的文件传输继续；Windows 同一连接的多屏窗口共用开关。
- 修复设备列表刷新时覆盖正在编辑的设备密钥、滚动位置跳动等问题，减少重复刷新。
- 修复传输取消、连接关闭和中继登录取消时的状态竞争，避免旧任务影响新连接。
- 修复 Windows 高 DPI 下按钮遮挡、传输表格截字、工具栏缩放不同步及被控提示条越界；Linux 表格列宽与行高随 DPI 和字体调整。
- 修复 Android 大字体横屏下密钥和共享名称输入框消失的问题，减少远程输入框对画面的遮挡。

三端安装包统一为 1.0.39，Android 沿用原签名，继续通过预发布渠道提供。建议连接两端一起升级。此次不调整视频分辨率、码率或画质策略。

DPI 验证使用 Windows 合成缩放通知、Linux Xvfb 和 Android 模拟器；不代表所有真机、混合 DPI 显示器或 OEM 输入法均已验证。
