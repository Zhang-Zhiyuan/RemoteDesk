# 1.0.17

修复 Windows 控制端复制粘贴失效：底层键盘转发曾绕过剪贴板同步，导致 Ctrl+V 粘贴远端旧内容或没有反应。现在先同步文字、等待确认，再执行粘贴，直连和中继共用此流程。

同时处理远端刚复制就粘贴、Ctrl+Shift+V、右 Ctrl、重复按键，以及失焦和重连后的延迟粘贴。复制非文本内容时，不再用本机旧文字覆盖远端剪贴板。

需要更新发起远控的 Windows 客户端，只更新中继服务器不会修复这个问题。三端安装包统一为 1.0.17；Linux 和 Android 本轮没有其他功能改动。APK 沿用原签名。

沿用预发布标记：12 项独立窗口/加密连接测试与 9 项真实公网中继检查通过，但不是三台真机六方向互控。Android 后台剪贴板、锁屏录屏和 Linux Wayland 限制仍在，Windows EXE 仍未做 Authenticode 签名。
