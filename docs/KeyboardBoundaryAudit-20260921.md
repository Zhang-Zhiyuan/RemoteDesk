# 按键与输入边界复查

2026-09-21，接续 [右 Shift 检查](KeyboardAudit-20260921.md)。本轮改源码和测试，未打包、推送或覆盖安装。

## 修复内容

- Windows：小键盘在 NumLock/Shift 状态变化后，数字键与导航键的松开事件能正确配对；Pause 不再使用无法完整表达它的单字节扫描码。
- Windows：长按 F11 只切换一次全屏；长按取回文件快捷键不再漏出未配对的 R。输入法候选状态变化、先松 Ctrl 再松 C，都不会吞掉已经发出的按键所对应的松开事件。
- Windows：队列拥堵后重试未入队的松键/松鼠标消息，只重试释放，不重放按下或移动。保留首次松鼠标的位置；新输入不能越过待释放消息。取消文件回传的临时输入屏障解除后，也会恢复重试。
- Windows：粘贴、切换输入法等合成组合键整组入队，容量不足时明确提示，不发送半组。迟到的剪贴板确认遇到新按下的无关按键时，只同步剪贴板，不执行错误的粘贴组合键；写剪贴板也校验原连接代次。
- Windows：按住 Ctrl 等键时不再自动触发文件拖出，避免内部 Escape 变成 Ctrl+Esc，或复制操作抬起用户仍按住的 Ctrl。普通远端拖动保留，并提示松开按键重新拖出或使用工具栏。取消路径只释放自己的鼠标，不释放用户修饰键；正常无修饰键拖出仍保留。
- Linux：补齐 NumLock、ScrollLock、Pause、Print、Menu 映射；不拦截带 Alt/Meta/AltGr 的应用快捷键。粘贴不再抬起用户仍按住的 Ctrl/Shift；长按只请求一次，失焦、停止输入后取消迟到的自动粘贴。
- 安卓：补齐裸回车的文字输入路径，拒绝无效 Unicode 代理码点；手机间提交的文本换行/制表符走文字通道，不误触工具栏导航动作。灭屏或自动解锁阶段拒绝输入时，清理当前会话的按住状态，避免被丢弃的松开事件造成残留。
- Windows/Linux 控制安卓：不支持的带修饰键操作不再悄悄变成单键或普通粘贴。正常文字、普通 Ctrl+V 仍保留。安卓工具栏 Tab 的原有快捷设置动作未更改，和文本中的制表符区分处理。

## 复现与验证

Windows 使用独立 WindowStation 内的真实 WinForms 窗口、临时认证回环连接和合成原生键盘记录。对端记录协议，不向用户桌面注入输入。Linux 使用 WSL 中独立 Xvfb 的 XTest 和 Tk。安卓本轮为单元测试与 lint，未操作手机。

保留的失败对照包括：Windows 新增窗口路由 10 组中 9 组失败、迟到粘贴确认 3 组失败、特殊键 27 项失败、队列释放 5 项失败，以及移动/滚轮越序和文件屏障恢复各 1 组失败。修复后均另跑复测，旧失败日志没有覆盖。

最终 Windows 全量：主测试集 **2,728 通过、11 跳过**，NativeDetail **53 通过**，无失败。11 项跳过需要显式开启 GPU 或真实远端测试，未计为通过。TRX 的汇总 `notExecuted` 字段为 0，但逐项结果确有 11 个 `NotExecuted`，和测试控制台一致；不能据此汇总字段宣称无跳过。

最终隔离检查：按键 **24/24**、剪贴板 **16/16** 通过，结果分别为 `windows/release-check/keyboard-modifiers.json` 和 `windows/clipboard-release-check/clipboard-shortcuts.json`。目录名表示 Release 构建验证，不表示已经发布。新增拖动检查直接验证取消入口的 Ctrl 保留、鼠标释放及正常 Escape 序列，没有发起实际 OLE 文件拖放；文件回传屏障检查使用受控的客户端屏障状态和真实事件/入队/回环链路，没有传输用户文件。

本地测试证据目录（均被 Git 忽略）：

- `artifacts/keyboard-boundaries-20260921/windows`：窗口、剪贴板协议、定向及全量 .NET 结果。
- `artifacts/audit-20260921-keyboard/windows/backpressure`：按键/鼠标释放队列的失败与通过记录。
- `artifacts/audit-20260921-linux-shortcuts`：Linux 718 项全量通过，0 跳过；包含实际 Xvfb 输入、焦点切换和受控的迟到确认。
- `artifacts/android-input-boundaries-20260921`：Debug、Release 各 729 项通过，0 跳过；lint 无错误，分别保留 6、5 条现有警告。

## 边界

自动化对端不等同于三端真机互连。本轮没有接管真实远端、读取用户剪贴板、修改系统键盘布局或锁屏设置，也没有验证所有实体键盘、国际布局、Wayland 和手机厂商系统。Android 录屏授权的系统限制没有因本轮按键修复而改变；Linux 小键盘回车仍使用逻辑 Return，没有声称区分物理主回车与小键盘回车。
