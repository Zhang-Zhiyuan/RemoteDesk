# RemoteDesk 1.0.36

Windows、Linux 新增被控提示：连接通过验证后，桌面会持续显示“正在被远程控制”。

- 浮条可拖动，不抢输入焦点；主窗口隐藏时仍会显示。
- 可在浮条上断开当前连接，保留被控端监听。连接结束后提示自动消失，新会话接管时不会被旧连接的清理误关掉。
- 修复 Linux 主动断开时，连接先关闭、停止重连消息还没发出的时序问题。
- 修复实测发现的 Windows 升级脚本启动问题；脚本未准备好时保留旧程序运行，避免升级失败后被控端掉线。

提示目前覆盖正常桌面，不覆盖系统锁屏或登录界面。已在 Windows 隔离桌面和 WSL/X11 运行检查；本轮未降低码率、分辨率或画质。

三端安装包统一为 1.0.36，Android 沿用原签名，仍按预发布发布。Ubuntu 22.04 请用 system-python 便携包；amd64 deb 要求 glibc 2.38。
