# 1.0.26

- 修复 Windows 鼠标右键复制粘贴不触发文本同步的问题。主控和被控端一起更新后生效；文件仍通过确认流程传输，不会自动上传。
- 修复 Windows 窄窗口、大字体下的文字和按钮遮挡。远控底栏放不下的操作移入“更多”，长诊断信息可以滚动查看。
- 改善 Linux 小窗口下的设备与文件弹窗，Android 接收文件列表改为后台加载，并明确显示保存位置和读取失败。
- 修复慢链路文件上传期间可能误判连接中断的问题，以及 Windows 部分后台任务异常导致应用退出的问题。
- 中继增加脱敏的断链原因日志，方便排查网络问题，不改现有连接密钥和传输协议。

建议连接两端都升级。新版自动右键文本同步目前针对 Windows 查看端；Android 被控端仍受系统后台剪贴板限制。

本版继续标记为预发布。Android 锁屏录屏授权、Linux Wayland 限制不变；Windows 锁屏控制仍需辅助服务，EXE 未作 Authenticode 签名。Windows 实际窗口检查 222 项通过；一条旧布局单测曾偶发失败，复跑通过，尚未定位原因。发布前核验不等同于所有物理设备均已验收。
