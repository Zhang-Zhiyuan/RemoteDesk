# RemoteDesk 1.0.33

- 修复 Windows 查看 4K 竖屏时，兼容解码器尚未输出首帧就被判定超时而黑屏的问题。首帧和大画面的处理有独立时限；成功解码后立即显示，不增加固定等待或画面缓冲。
- 修复一个解码后端失败时连带取消其他后端的问题，并补充失败原因。
- 修复竖屏备用采集可能出现横转、压扁的问题：不支持旋转的直接采集路径不再用于旋转屏幕，保留 WGC 和坐标准确的 GDI 采集及硬件编码。

已用两台 Windows 实机经公网中继验证竖屏、横屏、切屏及重新连接。原有带宽自适应仍保留；这次修复不代表所有设备或长时间网络抖动均已覆盖。

三端安装包统一为 1.0.33；Linux、Android 本轮无功能改动。沿用预发布标记及原 Android 签名，支持保留数据覆盖安装。现有兼容中继服务无需重启。Ubuntu 22.04 使用 system-python 便携包，amd64 deb 要求 glibc 2.38。
