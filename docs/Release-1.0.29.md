# RemoteDesk 1.0.29

- 修复右 Shift、左右修饰键、小键盘 NumLock 切换以及 Pause 的输入和释放问题。
- Windows 修复长按快捷键重复触发、输入法状态变化后漏松键、网络拥堵后的卡键和鼠标拖动残留。
- Windows 合成组合键整组发送；延迟粘贴不再被新按下的修饰键改变，也不跨重连写入旧剪贴板请求。按住修饰键时保留普通远端拖动，不自动触发有冲突的文件拖出快捷键。
- Linux 补齐特殊键映射，修复快捷键误拦截、粘贴抬起仍按住的 Ctrl/Shift，以及失焦后迟到的粘贴。
- 安卓补齐回车和文本制表符处理；不支持的组合键不再降级成错误的导航动作，灭屏或自动解锁阶段清理被丢弃的按键状态。

仍为预发布。检查范围与测试结果见 [输入边界检查](KeyboardBoundaryAudit-20260921.md)。这批按键修复不改变安卓录屏授权的系统限制，也不代表所有实体键盘、国际布局或锁屏环境均已验收。
