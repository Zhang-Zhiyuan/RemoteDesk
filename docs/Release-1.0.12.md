# 1.0.12

修复三端历史设备在 IP / 端口被另一台机器复用时误合并的问题。两个已经确认、但不同的设备标识不再共用记录、备注或保存的口令；同一设备换地址仍会合并。Windows 和 Linux 的列表匹配也同步调整，Windows 的备注和删除操作优先定位设备标识。

修复 Windows 自动探测在系统忙时，把内部 UDP / DNS 等待超时当成取消整个探测的问题。已填写的 IP 仍可进行有独立超时的 TCP 探测；用户主动取消仍立即生效。不会为探测发送连接口令。

没有改变视频分辨率、码率、JPEG 质量、录屏权限或公网路由策略。Android APK 沿用原签名，可以覆盖升级。

老版本设备没有稳定标识时，仍只能依赖地址，无法可靠识别 IP 被复用。升级前的误合并记录不能凭空还原；旧配置备份请保留。

本轮手机未接入 ADB，Android 使用独立模拟器验证。上轮 Linux → Windows 实际输入因测试窗口无法取得前台未完成；没有把这项记为通过，也不宣称三台真机六向完整验收。版本继续保留预发布标记。Android 锁屏录屏、Linux Wayland、Windows 首次登录前控制等限制见[权限说明](permissions.md)。Windows EXE 未做 Authenticode 签名。
