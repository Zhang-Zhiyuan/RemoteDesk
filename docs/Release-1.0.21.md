# 1.0.21

- Windows 缺少 FFmpeg 或旧版本不支持新采集接口时，后台安装固定版本编码组件。安装完成后，JPEG 会话自动重新尝试 H.264，不必重启。保留原有组件，不改系统驱动或 PATH；下载与程序均校验 SHA-256。
- 公网 TCP 不再重复发送完全相同的 JPEG 桌面。变化的画面照常发送，静止画面定期刷新，不降低画质。
- 修复 Linux / 中继在会话结束后仍刷新废弃视频缓冲的问题，减少断线重连时的关闭异常。正常传输及文件保存回执不变。
- 增加需认证的会话采集诊断，便于区分缺少编码器、采集回退和网络排队；兼容旧客户端。

Android 随版重新打包，沿用原签名。本次未连接手机，不将自动化测试当作手机实测。Android 录屏授权、Linux Wayland 和 Windows 系统登录验证的限制不变。

沿用预发布标记；Windows EXE 未做 Authenticode 签名。
