## 修复

- **后台异常误退出（Windows）**：原处理器把未观察的任务异常也当成致命异常，直接退出整个应用。现在标记异常已观察，记录不含消息正文、文件路径和凭据的代码诊断；真正的 UI/运行时未处理异常仍执行原退出流程。隔离进程实际运行消息循环，旧版在约 73 ms 退出，新版持续响应超过 3 秒。不能据此断言历史上每次退出都是这个原因。
- **慢链路文件上传误断（三端）**：文件和心跳共用 TCP，上传数据积压时，Ping 到不了接收端；没有画面更新时，控制端会在 18 秒后误断。真实文件发送及保存回执等待期间，给当前连接最多 150 秒的入站静默上限；普通连接仍是 18 秒，发送进度不会冒充入站活动。无回执旧端和 Windows 升级包另有最长 150 秒尾部排空保护，不会因提前到达的旧 Pong 而解除。失败和取消会清理状态，旧连接不能影响新连接。协议和画质不变。
- **文件确认/结果窗口（Windows）**：长路径会撑宽整窗，把“开始传输”挤出右侧；已约束列宽并增加可靠的外层滚动与 Tab 可达性，完整路径仍可选择复制。详见 [Windows 窗口记录](WindowsUiAudit-20260919.md)。
- **小窗口操作（Linux）**：修复文件确认按钮被挤掉、多候选设备窗口超出屏幕、新增设备固定宽度与重复缩放，以及加载完成后仍显示“正在读取”。保留可滚动完整路径和明确的确认/取消按钮。
- **接收文件列表（Android）**：存储查询移到后台，取消或离开页面后不再弹出过期结果；读取失败明确提示，不再当作空目录；保存位置改为可滚动、可选择复制的对话框。显式过滤未提交下载属于防御性改进，当前模拟器的 Provider 本身已经隐藏这些文件，不能算已复现的展示缺陷。
- **中继诊断**：原服务端会吞掉数据桥终止原因。现在每个通道记录一次有界、脱敏的分类，区分正常关闭、写入超时、连接错误与取消；不改变原超时策略。此改动只在源码中，未部署到正在使用的服务器。

Windows 慢接收证据为 `slow-file-before/slow-file-transfer.json` 与 `slow-file-after/slow-file-transfer.json`；后台异常证据为 `background-fault-before/` 与 `background-fault-after/`。所有路径相对本轮 artifacts 目录。

公网完整通过记录为 `relay-files-final-diagnostic/public-relay.json` 和 `relay-files-repeat/public-relay.json`。两轮耗时分别约 1.47 秒、92.16 秒，说明当时链路吞吐波动明显，不能把快的一次算作代码带来的提速。更早一轮回传中出现独立 EOF/RST，之后未复现，原因尚未确定；现有客户端证据不足以区分服务端写超时和网络中断。这与已可稳定复现并修复的 18 秒误断是两件事。

测试器还修正了相对/绝对路径比较误报，以及 Android 重复覆盖同名 SAF 测试文件导致旧大小缓存的问题。这些是测试夹具问题，不算产品修复。失败记录未删除或改成通过。

有一轮 Linux 整合测试与服务端源码编辑重叠，安装器正确拒绝了同版本、前后哈希不同的源码；停止全部编辑后重跑 606 项全部通过。最终测试期间源码保持不变。

## 未覆盖的环境

USB 安卓真机本轮未识别到，使用 Android 15 MuMu 隔离测试包；Linux 物理机 SSH 不可达，使用 WSL2 / Xvfb。没有把模拟器、loopback、单元测试算成六方向物理机互联，也未验证所有 OEM、Wayland、锁屏授权或长期弱网性能。

已卸载 Android 隔离测试包、清理其生成文件和 ADB 映射，将 MuMu 恢复到测试前的关闭状态。Windows 私有窗口站和临时中继测试节点已随探针结束；用于回归的本地文件与截图保留在 artifacts。

本轮不修改版本号、不替换 `release/`，不推送 GitHub、不覆盖远端安装。此前发布的包不包含这些新改动。
