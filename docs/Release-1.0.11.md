# 1.0.11

修复 Android 在小屏横屏、弹出键盘时把“原始像素”重新缩小的问题。高分辨率桌面也可以放到 1:1；旋转时短暂的空布局不会丢掉上次缩放。修改只涉及本地显示，不降低传输分辨率、码率或 JPEG 质量。

中转配置失败的提示在当前页面保留到下一次配置操作，不再被在线列表的自动刷新覆盖。错误密钥、身份不符和保存失败仍保留原有配置，后台目录与已建立的连接可以继续工作。

Windows / Linux 保留 1.0.10 的连接与画面策略。同步修正了 Windows 锁屏权限说明，并补强发布验收工具：同一套文件、剪贴板、编码切换、接管和重连检查现在可以明确走公网中转；测试超时和 Windows 文件占用不再轻易造成误报。

## 本轮核验范围

- Windows 完整自动化测试及 D3D11 解码、显示冒烟检查。
- Linux 图形界面自动化测试；Windows 到 Linux 真机的直连与真实公网中转功能验收。输入目标、文件和剪贴板均隔离在专用 Xvfb 中。
- Windows / Linux 公网设备地址上报，以及模拟地址移除、恢复后保持原会话。未修改网卡配置。
- Android 单元测试、Lint 和独立模拟器的查看端 UI 检查。新增小屏、1080P / 4K / 8K、极小键盘视口和输入坐标回归。

本轮手机未通过 ADB 连接；Linux → Windows 的实际输入测试因测试窗口无法取得前台而停止，没有向其他窗口发送输入。因此不将这轮记录视为三台真机的六向完整验收，发布仍保留预发布标记。Windows EXE 也未做 Authenticode 签名。

Android 锁屏录屏限制、Linux Wayland 和 Windows 登录前控制的边界未改变，见[权限说明](permissions.md)与[Windows 锁屏控制](WindowsLockScreen.md)。历史实测记录不能替代本版本在其他手机或系统上的验证。
