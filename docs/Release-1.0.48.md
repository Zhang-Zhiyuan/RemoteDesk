# 1.0.48

Windows 之间通过 TCP / 中继传输 H.264 时，按接收端实际收包情况控制发送，减少弱网下旧画面积压，
并改善带宽恢复后的发送速度。两端都更新后生效，不改变每帧编码画质，不切换 JPEG。

兼容旧版 Windows、Linux 和 Android。修复视频额度不足时备用采集可能连续空转的问题。
Windows 构建 SDK 更新到 8.0.428；Android、Linux 安装包保持同一发布版本。

限速测试有延迟与帧率的取舍，完整数据及测试范围见[实测记录](ReliableVideoFeedback-20261117.md)。
本轮没有修改 GPU 放大、原生文字补清范围或 H.264 的参考帧配置。
