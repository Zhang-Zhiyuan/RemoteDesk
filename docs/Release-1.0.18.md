# 1.0.18

修复小屏幕和高缩放下按钮被遮挡、输入框难以操作的问题。

- Windows：工具栏和远控底部按钮按宽度换行；连接、设备备注等弹窗支持滚动，切换输入框时自动保持可见。
- Linux：缩小远控窗口后操作栏仍然可见；修正缩放画面边缘的点击坐标。
- Android：大字体、小屏和横竖屏下重新安排标题、按钮与输入区，按钮不足一行时可以横向滚动。

保留 1.0.17 的剪贴板修复，安卓沿用原签名。Windows 仍默认申请管理员权限，EXE 未做 Authenticode 签名。

Windows、Linux 回归及 Android 单元测试、模拟器点击测试通过。沿用预发布标记：本轮未复测实体安卓手机和混合 DPI 多显示器；Android 锁屏录屏、后台剪贴板及 Linux Wayland 的系统限制没有改变。
