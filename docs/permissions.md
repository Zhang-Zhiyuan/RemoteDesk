# 权限与锁屏

## Android

Android 11 及以上可以勾选“免重复录屏授权（无障碍兼容模式）”。首次开启无障碍并启动被控后，日常连接和锁屏恢复不再申请录屏授权；覆盖安装也保留配置。点击“停止服务”会关闭自动恢复。

兼容模式使用系统无障碍截图，约 3 FPS，适合无人值守操作，不适合视频或游戏。需要流畅画面时关闭它，使用 H.264；Android 15 QPR1 及以上会在锁屏时终止录屏，这种模式仍需要重新授权。

“设置 / 清除自动解锁 PIN”是可选项。PIN 仅在手机本机使用 Android Keystore 加密保存，不会回显、上传服务器或写入日志。连接口令验证成功后才可尝试解锁，因此请使用足够强的连接口令。

自动解锁仅支持可识别的系统数字 PIN 键盘，不猜坐标、不移除锁屏。输入中断或失败后会阻止自动重试，正常解锁后才恢复；更改手机 PIN 后需更新保存值。重启后的首次解锁仍需在手机上完成。部分厂商还会单独申请“锁屏显示”和后台运行权限，首次配置时需允许。

不能绕过系统保护画面、用户撤销权限或“强行停止”。卸载会删除配置和密钥，不等同于覆盖更新。

亮屏、CPU 和 Wi-Fi 性能锁只在有已验证的远控连接时持有，断开后释放；等待连接不会一直亮屏。部分 realme / OPPO 系统会强制停止长时间后台持锁的应用，甚至清除无障碍权限。“忽略电池优化”不代表厂商的所有后台限制都已解除。

兼容截图超过 5 秒没有回调会作废旧请求并重试，迟到的旧截图不能覆盖新画面。截图权限暂不可用时，远端会显示原因。排队中的自动恢复请求不会撤销用户的主动停止，重复启动也不重置已有中继连接。

完整进程崩溃仍不能保证无人干预恢复：本轮 realme Android 16 故障注入中，系统保留无障碍开关但把服务标记为已崩溃，60 秒内没有自动恢复。已保护可捕获的服务启动异常并显示失败原因，但这不等于解决了所有进程崩溃或厂商后台限制。

## Windows

发布版的“安装 / 更新常驻权限”只需配置时授权：程序复制到 Program Files 下的受保护目录，注册当前用户登录时运行的最高权限任务。之后登录无需再次确认 UAC，也不保存 Windows 密码。必须使用当前用户自己的管理员权限；不能用另一个管理员账号代替当前用户配置。

普通“管理员重启”仍只提升本次进程。取消“开机自启”可停用常驻任务，重新勾选可启用；停用不强行中断现有连接。更换便携版文件后，可再次点击“安装 / 更新常驻权限”更新安装副本。旧安装副本保留用于回退。

同一用户会话只启动一个主程序，避免重复监听。主动“停止被控端”会同时关闭下次自动监听，再次启动时重新开启；关闭窗口、收入托盘和覆盖更新不会当作主动停止。接收更新时保留安装文件原有的访问权限。

这是登录后的交互式计划任务，不是登录前的 SYSTEM 服务。Windows 登录界面、锁屏及 UAC 安全桌面的远控尚未实现，不关闭 UAC，也不自动填写系统登录密码。

## Linux

首次填写口令并启动后，可记住口令、端口、画面设置和被控状态，并随桌面登录启动。口令用本机 AES-GCM 密钥加密，密钥和配置文件权限为 0600；这不是硬件密钥库，同一 Linux 用户或 root 仍能读取密钥。关闭“记住口令”会删除保存的口令和密钥，不保存 sudo / SSH 管理员密码。

意外退出最多自动重试三次，避免失败循环。主动停止会持久保存停止状态；关闭窗口后再次打开，会恢复上次开启的被控端。登录启动使用安装器的稳定启动入口，保留包内 Python 环境，并跟随版本更新。

只在发现缺少依赖时申请安装，安装完成后不会每次请求管理员权限。当前桌面后端基于 X11；Wayland 的完整录屏与输入授权恢复尚未实现。系统登录界面不是用户图形会话，不自动开启桌面免密登录。
