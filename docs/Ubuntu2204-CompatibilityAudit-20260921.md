# Ubuntu 22.04 实机兼容性检查

2026-09-21，在用户指定的 RTX 2080 Ti Ubuntu 22.04.5 LTS 实机上测试。
系统 Python 3.10.12、glibc 2.35、FFmpeg 4.4.2、Pillow 9.0.1、NVIDIA 驱动 535.230.02。
SSH 使用本机已有配置和认证，未修改 SSH 配置、登录设置、驱动、网络或系统软件。

## 修复

- 原 1.0.29 Linux 便携包在此机报 `GLIBC_2.38 not found`。启动器现在先检查内置运行时；不兼容时使用系统 Python 3.10+，不将内置 Python 3.12 的库路径带入系统 Python，不替换 glibc。
- 主机、协议检查、GUI、doctor 和系统 Python 便携包共用运行时选择逻辑。只在启动应用前选择一次；应用运行后报错不会再启动第二份。主机启动保持原 PID，GUI/doctor 的子进程环境不污染后续系统工具。
- Python 3.10 没有 `Task.cancelling()`，且 `asyncio.TimeoutError` 尚不是内置 `TimeoutError` 的别名。修正了中继路径取消、失败路径切换、超时分类和身份校验失败被超时掩盖的问题；用户主动取消仍保持取消语义。
- 补齐旧 Python/Pillow 的测试兼容性和无扩展名 Linux 启动器的 LF 换行规则。安装器测试补上包管理器及用户管理命令桩，避免测试环境缺少 `/usr/sbin` 时误调用真实系统命令。

## 验证结果

- Ubuntu 22.04：733 项 Python 测试通过，0 失败、0 跳过，包含独立 Xvfb 上的真实键鼠测试。
- Ubuntu 24.04 WSL 发布检查：733 项，0 失败；29 项需显式授权独立桌面的测试按默认发布流程跳过，已在上述实机隔离桌面补测。
- Windows 发布脚本契约检查：30 项通过。
- 本机 Windows 产品客户端经 LAN 直连实机上的独立 RemoteDesk 主机：11 项功能检查通过，包括错误密钥拒绝、画面及屏幕选择、JPEG/H.264 切换、后连接替换前连接、同一客户端两次重连。
- 文件双向传输通过：131,103 字节文件、重名文件分别保留、空文件、含中文文件的文件夹、返回文件；接收侧逐字节/SHA-256 复核。未读取或覆盖 Windows 的真实剪贴板。
- 在同一 LAN 会话中，已知中文、emoji 和换行文本写入 Linux 剪贴板后读回一致。第一次附加诊断未显式启用协议解析器的剪贴板文本字段，得到假阴性；修正诊断后重新完整执行通过，无需修改产品剪贴板代码。
- 同机隔离桌面 H.264 采集：NVENC，1920×1080，连续 180 帧约 59.2 FPS；重连 60 帧约 60.6 FPS。NVDEC 解码 60 个输入单元得到 58 个非黑帧，剩余 2 个仍在有界流水线中；软件解码得到 60 个非黑帧。不能将此结果当作公网端到端延迟或帧率。
- 实际 Tk 界面截图检查覆盖三种缩放、小窗口、设备对话框和文件确认对话框；主页面有滚动区域，文件确认/取消按钮保持可见。
- 修复后的便携包在 Ubuntu 22.04 上完成启动器、doctor 和 Windows LAN 功能复测。发布包 SHA-256 在上传前后匹配。

## 测试边界与交付

上述兼容性检查期间，机器处于 GDM 登录界面。录屏、鼠标、键盘、剪贴板仅针对临时创建、关闭 TCP 访问且使用独立 Xauthority 的 Xvfb，未接管用户的真实桌面。
真实 Xorg 登录桌面、Wayland、锁屏恢复和此机经公网服务器的中继会话尚未实测；本轮的中继测试使用隔离 TLS 测试服务，不改已有公网服务器。

系统缺少 xclip/Xvfb；本轮只下载并解包至临时目录，没有系统安装。未永久安装 RemoteDesk、启用自启动或设置设备密钥。结束前确认无存活测试进程，再删除约 163 MB 的远端临时目录；证据已下载保留。
