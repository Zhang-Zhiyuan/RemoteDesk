# 1.0.16

- 中继在线设备可修改共享名称，同一服务器的其他客户端刷新后也能看到。名称保存在服务器，重连或换 IP 不会丢失；清空后恢复原机器名。
- 修复三端文字剪贴板的复制、剪切、粘贴和延迟回复处理。粘贴等待远端写入确认，空回复和旧连接回复不会覆盖新复制的内容。
- 文件传输增加保存回执和必要的确认、失败提示，直连和公网中继都支持。Android 的“更多 → 发送文件”可主动选文件发送。
- Windows 默认申请管理员权限，开机自启同步适配；修复从 PowerShell 7 启动后远程更新校验失败，以及早期失败时无法自动重启旧版的问题。

Windows、Linux、Android 版本统一为 1.0.16，APK 沿用原发布签名。Windows 系统 UAC 确认仍保留，没有关闭系统权限检查。

沿用预发布标记：近期 Android 界面验收使用 Android 16 模拟器，不能代替所有厂商真机验证；未重新完成三台真机六方向互控。Windows EXE 未做 Authenticode 签名。Android 锁屏录屏限制、后台剪贴板限制，以及 Linux Wayland 限制仍然存在。

专项检查记录：[剪贴板](ClipboardSync-20260912.md) · [文件传输与中继](FileTransferRelay-20260912.md)。成品在 GitHub Release 和仓库 `release/` 目录，构建提交与哈希以发布清单为准。
