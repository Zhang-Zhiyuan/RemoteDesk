# 1.0.25

- 修复 Windows 切回本机后，远控窗口仍可能拦截复制快捷键的问题。
- 三端发送文件前查询并确认远端接收位置，完成后显示实际保存路径；重名、部分失败和中断都有逐项结果。
- 文件已取回但剪贴板被占用时，仍显示已保存文件，不再误报成文件没有收到。
- 修复排队传输期间切换设备、断线状态残留，以及部分大字体和窄窗口下的显示问题。
- Android 接收文件后读取系统实际保存的文件名，公共下载目录不可用时明确提示后备位置。

直连和公网中继均适用。旧版被控端不能报告接收位置时会明确提示，建议两端一起升级。

本版继续标记为预发布。Windows 锁屏控制仍需在被控机安装辅助服务；Android 锁屏录屏授权和 Linux Wayland 限制未改变。手机本轮未做真机验收，Windows EXE 仍未作 Authenticode 签名。
