# 1.0.24

- Windows、Linux、Android 的中继选路加入近期握手延迟、抖动和失败情况比较。
- 连续三轮明显更好、且原首选已保持三分钟，才调整后续连接的首选线路。小幅差异、单次尖峰不切换。
- 当前线路建连失败仍立即尝试备用线路；已经建立的远控会话不会为了换线路而被断开。
- 后台采样限频、限时、限制并发，不登录中继、不修改设备记录。Android 不为采样唤醒蜂窝网络或额外使用计费网络。

选路只比较已连接、系统策略允许的网络，不会自动切换 Wi-Fi 名称，也不会绕过 VPN。
这是建连选路优化，不是给已建立的 TCP 会话做无缝迁移；清晰度和视频编码策略未改动。

三端共享策略测试通过，本机双网卡完成 217 秒真实公网握手检查；手机本轮未连接，未做手机真机验收。
