# RemoteDesk 1.0.38

- 修复 Windows 多屏分窗时，旧窗口迟到的松键或断线清理误放开另一个窗口按键的问题，包括右 Shift 和鼠标拖动。锁屏辅助进程也按连接隔离按键归属。
- 调整 Windows 锁屏辅助进程的连接容量，满足最多 4 屏各自的采集、输入和健康检查，不再沿用单窗口时的 3 条连接限制。
- 修复 Linux 被控提示点击“断开”失败后无法重试的问题；同一次请求不会重复执行，新连接也不会被旧请求覆盖。
- 修复 Windows 深色远控工具栏中，禁用按钮文字过黑、不易辨认的问题；按钮仍保持禁用状态。
- 修复静态桌面 H.264 恢复请求可能一直等不到新画面的问题：仅在有恢复请求且采集已静止时重建当前屏幕的采集，不影响正常出帧或另一块屏幕。

不调整视频分辨率、码率或画质策略。三端安装包统一为 1.0.38，Android 沿用原签名，继续按预发布提供。双屏独立窗口仍限 Windows 控制 Windows；被控提示不覆盖系统锁屏或登录界面。
