# 三端界面检查（2026-09-14～15）

这轮检查的是主界面、弹窗、窄窗口和大字体，不是新的六方向网络性能认证。
截图、安装记录和原始测试结果保存在本地忽略目录 `artifacts/ui-audit-20260914/`。
手机截图不上传仓库。

## 修改

- Windows：主页面统一由外层滚动，窗口缩小时工具栏换行；修复隐藏页面提前测量导致工具栏折叠、输入框变窄的问题。数字输入保留最小宽度，设置字段跟随所在列展开。窄窗口中设备列表和状态区有独立的可用高度，键盘焦点能滚动到对应控件。
- Windows：画面模式缩短为“自动（推荐）”“清晰（JPEG）”，说明真实的硬件加速和 JPEG 回退行为，移除不存在的“仅 H.264”提示。“同步更新”改为“同步程序版本”，保留双向版本同步含义。
- Linux：按钮按实际文字宽度换行，说明文字随窗口换行；设备表格使用自身的横纵滚动条，不再撑宽整页。大字体下列表行高按字体测量，输入栏和标题也适应窄窗口。“公网中继”和“修改共享名称”等用语更明确。
- Android：设备页不再优先显示本机被控权限警告，明确控制其他设备无需本机录屏授权；被控页仍保留实际权限要求。窄屏/大字体下发现按钮上下排列；新增设备的端口提示改为短标签和可换行说明；服务器管理员密码说明常驻，高级设置明确显示展开/收起状态；远控手势提示允许两行，工具栏滚动提示不自动淡出。

这轮没有改画质算法、设备密钥、TLS 验证规则、锁屏或 Wi-Fi 设置。
