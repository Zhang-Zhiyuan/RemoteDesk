# 1.0.27

- 修复 Windows 更新后锁屏辅助进程未重新加载、导致锁屏无画面的问题。保留身份校验，不自动安装或启用已停用的服务。
- 锁屏控制失败时显示更准确的原因，避免一律提示重新启用或申请管理员权限。
- Linux 断线后停止文件夹扫描和压缩，小窗口的文件确认框优先显示接收位置。
- Android 取消接收文件列表时通知后台查询停止，避免过期结果重新弹出。

Windows 锁屏修复已通过公网在实机上验证画面与重连；右键剪贴板、公网文件确认与传输、窗口布局也已复测。

本版继续标记为预发布。手机和 Linux 真机本轮离线，尚未完成新版真机验收；Android 锁屏录屏授权、Linux Wayland 和 Windows 安全注意序列的限制不变。Windows EXE 未作 Authenticode 签名。
