# RemoteDesk 1.0.34

- 安卓远控工具栏固定显示“更多”，窄屏、大字体时不必先横滑寻找菜单。
- Windows、Linux 远控窗口显示正在连接的设备和连接方式，不再把直连输入框的旧地址或中继服务器误当成远端机器。
- Windows 恢复画面后清除旧的解码故障提示；同一解码器继续出图时也能正确更新状态，不增加逐帧 UI 刷新或视频缓冲。
- 更新布局回归测试，覆盖新增的手机导航按钮，并检查小窗口、字体放大、输入和只读状态。

本轮运行了 Windows 隔离桌面、WSL/X11、Android 16 模拟器和真实公网中继测试。文件测试覆盖传输前确认、接收位置、重复文件名、保存回执和剪贴板；模拟器测试不等同于手机真机兼容认证。

三端安装包统一为 1.0.34，沿用 Android 签名及预发布标记。Ubuntu 22.04 请用 system-python 便携包；amd64 deb 要求 glibc 2.38。现有兼容中继服务无需重启。
