# RemoteDesk 1.0.28

- 三端补上直连防自连检查，覆盖本机 IP、回环地址、主机名解析、历史节点和自动重连；中继内部转发不受影响。
- Windows 修复锁屏前后屏幕标识变化时的恢复逻辑，临时单屏映射不改变原屏幕选择；旧坐标输入被拒绝，不自动重放。
- Windows 更新时会一并更新已启用的旧锁屏辅助服务，处理主程序与辅助服务分装在不同目录的情况；失败时尝试恢复原配置，不自动安装或启用已停用的服务。
- Linux X11 增加会话内文字剪贴板自动同步，处理并发复制、回传去重和断线清理；自动读取不阻塞界面。
- Linux 小窗口工具栏和状态详情更易访问；安卓修正停止录屏、切换被控模式、无障碍状态变化后的提示和恢复入口。

仍为预发布。Windows 密码 / PIN 的真实解锁、Linux 原生 Wayland 锁屏及不同安卓厂商后台策略尚未完整验收。安卓系统撤销录屏授权后仍需重新授权。

防自连在直连认证前检查实际 IP，在已知设备标识时也提前拦截。未知公网 NAT 回环或外部端口转发可能隐藏本机地址，只能在认证后收到设备标识时停止，因此不能保证这类路径不触发原会话接管。Linux 特殊应用重复复制相同文字但不报告变更时，仍需手动发送；不可靠的剪贴板环境不会自动取回覆盖本机。
