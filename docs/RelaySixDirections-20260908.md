## 补齐与修正

1. Linux 新增“公网中转”页和 asyncio TLS 传输适配器，支持本机上线、选择目标、
   手动刷新、断开和重连，发行脚本加入新模块。配置原子保存到 `0600` 文件。
2. Android 新增折叠式中转面板、Keystore 配置存储、foreground host 注册和原生
   TLS viewer 路由。面板只在前台展开时轮询，录屏/服务停止时关闭注册与数据通道。
3. 两端先校验证书身份，目标仍需 RemoteDesk 远控口令；中转会话禁用 LAN UDP，
   连接失败不能悄悄转直连。本机不能自连，配置变更后的旧目录与状态消息被丢弃。
4. 收尾修正连接取消的竞争窗口、停止后的定时器释放，以及 Android 被缓存后
   固定频率心跳可能集中补发的问题。网络在 TLS 协商阶段断开不再误判为证书变更。
5. 手机负面实测发现错误指纹/访问密钥被统一显示成“检查口令与双方版本”。改用
   固定且独立的中转身份错误类型；真机复测已正确显示“核实证书指纹”或“中转访问
   密钥被拒绝”，均未创建会话。修复前后结果分别保留在 `android-negative` 与
   `android-negative-fixed`，不掩盖失败记录。
