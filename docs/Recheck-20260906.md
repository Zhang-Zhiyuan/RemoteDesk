- Linux 文件回传顺序测试隔离真实剪贴板读取，仍实际执行临时文件准备、取消、排队重试及终态/预览排序。此前并行构建时该用例因真实剪贴板工具耗时出现超时；不通过增加超时或削弱排序断言掩盖问题。

## 发布校验

上次手工合并 Windows 新包与 Linux/Android 原包后的清单，虽然单文件 SHA-256 匹配，却不能通过项目的完整发布检查：scope 不在标准枚举中，源码指纹也不匹配整理后的工作区。本轮使用标准发布脚本重新构建三端包并自动生成清单，不放宽 scope、源码指纹、工具链、签名元数据或 ZIP 内容校验。

构建仍为 `-AllowDirtySource` 内部候选：Git 遗留锁和缺少远端不影响本地测试/构建，但不应把它标记为已提交源码的正式发布。没有在此轮改写 Git 历史或上传 GitHub。
