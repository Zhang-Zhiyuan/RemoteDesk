# RemoteDesk 1.0.32

- 控制安卓手机时，Windows、Linux、安卓界面均增加“返回、主页、最近任务”。小窗口自动调整，只有观看权限时禁用。
- 修正安卓被控时的滚轮方向；Android 13+ 改进密码框、中文和 emoji 输入，避免把密码掩码当作原文写回。
- 安卓在线设备列表不再因周期刷新跳动，长设备名和地址显示更完整。
- 修正 Linux 硬件编码遇到短暂停顿后误切回 JPEG 的问题，仍丢弃过期画面，不增加缓冲延迟。

六个互控方向均已通过公网中继连接 Windows、RMX5200 真机和 2080 Ti Ubuntu 实机验证，具体覆盖范围见[实测记录](CrossPlatform-Interop-20260922.md)。安卓控制端的新导航栏另做了模拟器小屏和大字体回归，不代表已覆盖所有厂商、锁屏或 Wayland 场景。

沿用预发布标记和原安卓发布签名，支持保留数据覆盖安装。Ubuntu 22.04 使用 system-python 便携包；amd64 deb 要求 glibc 2.38。现有兼容公网中继无需重启或升级。
